## 🎮 About the Project

**The Haunted Cruise** is a first-person horror puzzle game where the player awakens aboard an abandoned cruise ship haunted by spirits from the Greek–Italian conflict.

Players must solve environmental puzzles, uncover hidden secrets, and escape while experiencing cinematic horror sequences and supernatural events.
